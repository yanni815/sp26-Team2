**Version:** 1.0

**Purpose:** This document outlines comprehensive test scenarios for each functional requirement (user story) in the SitSmart system.

## Actors
- Provider P: Babysitter
- Customer C: Parent

## Use Cases

#### 1. Provider: Register & manage profile
1. Babysitter logs in for the first time and creates a profile.
2. Babysitter edits profile.
P1 exits the app.


#### 2.Parent:  US‑CUST‑001 — Register & manage profile, US-CUST‑003 — Discover Babysitters, US‑CUST‑005 — Book a sitter.
1. Parent logs in.
2. Parent Looks for available sitters 
3. Parent books a sitter

#### 3. Customer: US‑CUST‑008 — Pay Babysitter 
1. Parent logs in.
2. Parent goes to their bookings.
3. Parent pays Babysitter.


#### 4. Parent: US‑CUST‑005 — Message Babysitter
1. Parent logs in and views babysitters.
2. Parent sends a message to Babysitter.

#### 5. Babysitter:  — Replies to message
1. Babysitter logs in and views messages.
2. Babysitter writes a response.




#### 6. Parent: US‑CUST‑007 — Write a review
1. Parent logs in and views babysitters.
2. Parent writes a review for the sitter.
